# City boundary

Census TIGER Place boundary for Davis, California (GEOID 0618100).

This is the official analysis extent used throughout the paper (~25.92 km²). Fair USDA comparison, canopy fractions, and neighborhood screens are all clipped to this polygon.

Files: `davis_city_boundary.shp` and sidecar files (`.dbf`, `.shx`, `.prj`, `.cpg`).
