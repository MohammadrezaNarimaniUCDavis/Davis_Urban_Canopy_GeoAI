# Data directory

All analysis uses the Census TIGER municipal boundary in `boundary/`.

| Folder | On GitHub | From Zenodo | Contents |
|---|---|---|---|
| `boundary/` | yes | yes | Davis city shapefile (official extent, ~25.92 km²) |
| `derived/` | tables only | rasters / GeoJSON | 100 m analysis table plus pipeline products |
| `reference/` | placeholder README | yes | USDA/CAL FIRE 2022 canopy raster |
| `raw/` | placeholder README | NAIP GeoTIFF | Optical input for crown detection |

Dataset DOI: https://doi.org/10.5281/zenodo.21925527

Unpack instructions: [`docs/DATA.md`](../docs/DATA.md)
