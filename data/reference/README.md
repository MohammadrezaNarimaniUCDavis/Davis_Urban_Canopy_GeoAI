# Reference canopy

Place the USDA/CAL FIRE 2022 urban canopy raster here as:

```
Davis_canopy2022.tif
```

Download it from the Zenodo dataset (`reference/` inside `Davis_Urban_Canopy_GeoAI_derived_data.zip`):

https://doi.org/10.5281/zenodo.21925527

Required for:

```bash
python scripts/05_fair_usda_compare.py
```

The raster is not stored on GitHub. Original USDA/CAL FIRE terms of use apply.
